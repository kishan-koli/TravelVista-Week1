## 🌍 About The Project

**TravelVista** is a modern travel and tourism website concept designed to provide users with an engaging way to discover destinations and explore curated travel packages.

This project was developed as part of **Week 1 — Transforming Wireframes into Static Web Pages** of my Frontend Web Developer Internship.

The main goal was to convert a professional wireframe/design concept into a structured, responsive and visually appealing static webpage using **HTML5 and CSS3**.

## 📱 Responsive Design

TravelVista is designed to work across different screen sizes.

### 💻 Desktop

Multi-column layouts are used to display destinations, packages and benefits.

### 📱 Mobile

The layout automatically adapts to smaller screens using CSS media queries, with content changing into single-column layouts where necessary.
